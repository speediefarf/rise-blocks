Comeback Quiz

A quiz with a built-in comeback round. Learners answer everything once; after that, each new round asks only the questions they missed, until all of them are mastered. Wrong answers stop being a dead end and become the study plan.

Live demo — this is the actual block file running, the same one you copy below. Deliberately miss a couple of answers to see the comeback round.

Download the file

Add it to Rise

  1. Copy the code below (or download the file).
  2. In your Rise 360 course, insert a custom code block where the check belongs and paste the entire file in — or upload it as a zip package if your version of Rise asks for one.
  3. Preview the lesson. The block is fully self-contained: no hosting, no external calls, nothing else to configure.

Make it yours

  • Questions live in one clearly marked QUESTIONS list at the top of the script — question, options, the correct answer's position, and the feedback text. Edit text only; no logic to touch.
  • Change the quiz title in the heading at the top of the file.
  • Restyle in the <style> block — the accent color is #0e7a5f throughout.

Teaching note

When to use it: as the closing check of a lesson, where the goal is mastery rather than a grade. A standard Rise quiz tells learners their score and moves on; this one spends their retry time exactly where they're weak.

Running it live: watch for the first-try score at the end — it's a clean read on which questions were genuinely hard for the room, versus which were careless clicks. Those hard questions are your reteach list.

Variation: write the feedback (why) fields as pointers back to the lesson — “see the golden signals table” — so a missed question routes the learner to the exact spot that teaches it.
