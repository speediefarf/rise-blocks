Code reading

Code Walkthrough

Pasted code in a course usually gets skimmed. This block walks a snippet one idea at a time: each step highlights the lines that matter and explains them in plain language, and the last steps turn reading into a bug hunt. The sample walks a tiny error-rate function with a divide-by-zero hiding in it.

Live demo — the actual block file. Arrow keys work too: ← and → move between steps.

Download the file

Add it to Rise

  1. Copy the code below (or download the file).
  2. In your Rise 360 course, insert a custom code block where the walkthrough belongs and paste the entire file in — or upload it as a zip package if your version of Rise asks for one.
  3. Preview the lesson. Nothing to host and nothing external to load.

Make it yours

  • The snippet is the CODE list at the top of the script — one string per line, in order.
  • Steps are the STEPS list: the 1-based line numbers to highlight, a title, and the explanation. Add or remove steps freely; the dots and counter rebuild themselves.
  • A step can carry a fix snippet, shown in a dark box — built for “here's the repair” moments.
  • Works for any language. The sample is JavaScript, but NRQL queries and config files walk just as well.

Teaching note

When to use it: anywhere a course currently shows a code block and hopes. Reading code is a separate skill from writing it, and it's the one working engineers use daily — this block teaches the narrated, line-by-line read you'd do at a whiteboard.

Running it live: at the “spot the bug” step, stop and take answers before advancing. The room will find the empty-input case faster than they expect, which is the moment the “read the edges first” habit sticks.

Variation: delete the fix step and end on the bug. Learners propose the guard themselves — in a discussion block, or out loud in a live session — then compare against yours next lesson.
