House rules

Four constraints every block in this library is built under.

One file, zero dependencies

HTML, CSS, and JS in a single file. No libraries, no build step, no external calls — so nothing can break when a CDN changes or a network blocks it.

Honest mechanics

If a block is scripted, it says so. Learners are told how the trick works; the mechanism is part of the lesson, never hidden from them.

Content lives in one obvious place

Questions, code steps, and dialogue sit in a clearly marked data section at the top of the script, so adapting a block means editing text, not hunting through logic.

A teaching note ships with it

Every block page includes when to use it, how to run it in a session, and the variations worth trying. The pedagogy is part of the artifact.
